# VTOP Survey Bypasser

A lightweight, automated Chrome Extension designed to complete the mandatory faculty feedback surveys on VTOP in seconds.

---

## ⚡ Features

- **One-Click Automation**: Automatically rates all questions with 5 stars.
- **Intelligent Field Handling**: Skips open-ended suggestion/comment boxes to keep feedback valid without injecting dummy text.
- **Auto-Navigation**: Automatically moves through all pending course surveys until every single one is submitted.
- **Privacy First**: Fully client-side. No trackers, no analytics, no external servers, and zero data collected.

---

## 📥 Installation

1. Go to the **[Releases](https://github.com/)** tab on the right side of this repository.
2. Download `VTOP_Survey_Bypasser_Final.zip` from the latest release.
3. Extract the downloaded `.zip` file into a regular folder on your computer.
4. Open Google Chrome (or Brave / Edge) and navigate to:
   ```text
   chrome://extensions/
   ```
5. Enable **Developer mode** using the toggle switch in the top-right corner.
6. Click **Load unpacked** in the top-left corner.
7. Select the folder containing `manifest.json`.

---

## 🚀 How to Use

1. Log in to **VTOP**.
2. Navigate to the **Student Feedback / Survey** page.
3. Click the **VTOP Survey Bypasser** icon in your Chrome toolbar / extensions menu.
4. Click **Start Automation**.
5. Sit back and watch it complete all your course feedback forms automatically!
